# 📚 ENCCEJA 2027 - Plataforma de Estudos Completa

Uma plataforma educacional interativa para preparação do **ENCCEJA** com 36 semanas de estudos, 5 simulados especializados e 144 exercícios de fixação.

## ✨ Características

- ✅ **36 Semanas de Estudos** - Divididas em 4 blocos temáticos
- ✅ **Material Teórico** - Páginas específicas de cada semana
- ✅ **Aulas YouTube** - Links de video aulas para cada tópico
- ✅ **144 Quizzes** - 2 perguntas de fixação por semana
- ✅ **5 Simulados** - Matemática, Ciências Naturais, Ciências Humanas, Linguagens e Final
- ✅ **90 Questões** - Simulados estruturados (18 por bloco + 72 final)
- ✅ **Cronômetro** - Tempo de simulado em tempo real
- ✅ **Progresso** - Barra visual com % de conclusão
- ✅ **Feedback Imediato** - Respostas corretas/incorretas al momento
- ✅ **Salva Localmente** - localStorage para persistência
- ✅ **Responsivo** - Funciona em mobile, tablet e desktop
- ✅ **Sem Dependências** - 1 arquivo HTML puro

## 🎯 Como Usar

### 1. Abrir a Plataforma
```bash
# Duplo-clique em:
index-encceja-completo-final.html
```

### 2. Estudar (ABA 1: Plano de Estudos)
```
- Clique em um card de semana para expandir
- Leia o material teórico (páginas indicadas)
- Clique no link da aula (YouTube)
- Responda o quiz (2 perguntas)
- Marque ☑ como concluído
```

### 3. Fazer Simulado (ABA 2: Simulados)
```
- Clique em um dos 5 cards coloridos
- Responda as questões (cronômetro roda)
- Use: ⏸ Pausar, ✓ Finalizar, ✕ Fechar
- Veja resultado com % de acerto
```

## ⏱️ Funcionalidades do Simulado

- ⏸ **Pausar** - Pausa cronômetro e sessão
- ✓ **Finalizar** - Vai direto ao resultado
- ✕ **Fechar** - Volta aos cards (sem perder progresso)
- 📊 **Progresso Visual** - Barra de % das questões
- ✅ **Feedback Imediato** - Resposta certa/errada na hora
